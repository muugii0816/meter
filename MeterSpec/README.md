# MeterSpec

This folder contains meter specification documentation, including model introduction, working principles, and supported remote data types.

## Purpose
- Store Datasheets for registered meter models in the system.
- Provide quick reference for model capabilities and remote data access.
- Help developers and users understand meter interfaces, protocols, and measurement outputs.

## Contents
- `datasheet.md` — a general datasheet template for meter models.
- Additional files per meter make/model can be added here.

## Suggested structure
- `datasheet.md` — general overview and model specs
- `generic-meter-model.md` — example meter model documentation
- `communication-protocols.md` — supported communication types and commands
- `data-points.md` — available remote data points and formats
